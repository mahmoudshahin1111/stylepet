<h1 align="center">Devpet</h1>

<p align="center">
  Devpet is an open-source web tool for transforming CSS color variables for styling purposes.
</p>

<p align="center">
  <em>This project is archived and no further updates will be made.</em>
</p>

---

## What it does

Devpet helps you work with CSS color variables and styling-related color calculations in a simple Vue-based interface.

## Features

- Transform and compare CSS color values
- Preview styling-friendly color changes
- Lightweight Vue + Vite app
- Easy to run locally

## Project status

This repository is archived.

- No new features will be added
- No maintenance updates will be published
- Use it as-is for reference, learning, or as a small utility

## Tech stack

- Vue 3
- TypeScript
- Vite
- Vuetify
